INTRODUCTION:

Generative Artificial Intelligence (Generative AI) is a type of artificial intelligence that can generate new content such as text, images, code, and other information based on user instructions. Large Language Models (LLMs) such as ChatGPT can understand natural language and generate meaningful responses.

A prompt is an instruction or question given to an AI model to obtain a desired output. Prompt engineering is the process of designing and improving prompts so that the AI produces accurate, relevant, and useful results.

In this experiment, a prompt-based Personal Productivity Assistant is developed using ChatGPT. The assistant is designed to help users organize their academic and personal activities. It can prioritize tasks, create schedules, provide reminders, suggest wellness activities, and answer general queries.

PROBLEM STATEMENT:

Students often have to manage assignments, examinations, projects, personal activities, and deadlines at the same time. Poor planning can result in missed deadlines, stress, and reduced productivity.

The proposed Personal Productivity Assistant uses a Large Language Model to understand natural-language instructions and provide personalized productivity suggestions. The system can organize tasks according to urgency and importance and generate a practical daily schedule.

EXPLANATION:

A prompt-based application communicates with an LLM through natural-language instructions instead of traditional programming alone. The quality of the output depends largely on the quality and clarity of the prompt.

The Personal Productivity Assistant consists of several major functions:

1. TASK MANAGEMENT
   The assistant accepts tasks entered in natural language and organizes them according to their priority, deadline, and estimated completion time.

For example, the user can enter:

"I have to submit my DBMS assignment by 8 PM and prepare for a Python test tomorrow."

The assistant identifies both activities and determines which task should be completed first.

2. TASK PRIORITIZATION

Tasks can be categorized as:

* High Priority – Urgent and important tasks.
* Medium Priority – Important tasks that can be completed later.
* Low Priority – Tasks that are less urgent.

This helps the user focus on the most important activities first.

3. SMART SCHEDULING

The assistant can create a daily schedule based on the available time and the user's tasks. It can divide a large task into smaller sessions and suggest breaks between activities.

For example:

"Schedule my study time between 8 PM and 11 PM."

The assistant can divide the available time into study sessions, revision, assignment work, and short breaks.

4. REMINDER MANAGEMENT

The assistant can understand reminder requests written in natural language.

Example:

"Remind me to complete my assignment at 7 PM."

The assistant identifies the activity and requested time and presents it as a reminder task.

5. WELLNESS TIPS

The assistant can provide simple productivity and wellness suggestions such as:

* Taking short study breaks.
* Drinking enough water.
* Performing simple stretching exercises.
* Reducing unnecessary screen time.
* Maintaining a regular sleep schedule.
* Taking breaks after long periods of concentration.

6. GENERAL QUERY HANDLING

The assistant can also answer general questions and explain academic concepts in simple language.

Example:

User:
"Explain inheritance in Python in simple words."

Assistant:
"Inheritance allows a new class to use the properties and methods of an existing class. It helps reduce repeated code and supports code reuse."

PROMPT USED:

"Design a personal productivity assistant that can help manage daily tasks, schedule reminders, suggest wellness tips, and answer general queries. The assistant should interact using natural language and be adaptable to the user's changing preferences over time."

BASIC PROMPT:

"Act as a personal productivity assistant. Help me organize my daily tasks and suggest a suitable schedule."

IMPROVED PROMPT:

"Act as my personal productivity assistant. Analyze my tasks based on urgency, importance, deadline, and estimated completion time. Create a practical schedule using my available time. Clearly identify high-priority tasks, suggest short breaks, and keep the response simple and easy to follow."

ADVANCED PROMPT:

"Act as an intelligent personal productivity assistant for a college student. Help organize academic and personal tasks based on priority, deadline, available time, and estimated duration. Create a realistic daily schedule, identify urgent tasks, suggest suitable study breaks, provide simple wellness tips, and answer general academic queries. Avoid unrealistic schedules and ensure that the plan contains sufficient rest. Learn from my feedback and adapt future suggestions according to my preferences."

PROCEDURE:

1. Open ChatGPT or another suitable Large Language Model.
2. Define the requirements of the Personal Productivity Assistant.
3. Identify the major functions such as task management, scheduling, reminders, wellness suggestions, and general queries.
4. Create a basic prompt describing the required assistant.
5. Enter the prompt into ChatGPT and observe the generated response.
6. Provide sample daily tasks as user input.
7. Ask the assistant to prioritize the tasks according to urgency and importance.
8. Ask the assistant to create a daily schedule based on available time.
9. Provide feedback on the generated schedule.
10. Improve the original prompt by adding more specific instructions.
11. Test the improved prompt with different user inputs.
12. Compare the basic and advanced responses.
13. Use user preferences to make the assistant more personalized.
14. Record the final output and analyze its usefulness.

ITERATIVE PROMPTING:

Iterative prompting means repeatedly improving a prompt based on the quality of the generated output.

Initial Prompt:

"Help me plan my day."

Improved Prompt:

"Help me plan my day by organizing my tasks according to priority and deadline."

Further Improved Prompt:

"Create a realistic daily schedule for a college student. Prioritize tasks according to urgency and deadline, include study sessions and short breaks, and avoid scheduling too many activities at the same time."

Final Advanced Prompt:

"Act as my personal productivity assistant. Organize my academic and personal tasks based on urgency, importance, deadline, available time, and personal preferences. Create a realistic schedule with focused work sessions and short breaks. Highlight urgent tasks, identify pending work, suggest simple wellness activities, and modify future schedules based on my feedback."
