# Exno.7-Develop a prompt-based application tailored to their personal needs, fostering creativity and practical problem-solving skills while leveraging the capabilities of large language models.

# Date: 27-08-26
# Register no.: 212223020014
# Aim: To develop a prompt-based application using ChatGPT - To demonstrate how to create a prompt-based application to organize daily tasks, showing the progression from simple to more advanced prompt designs and their corresponding outputs.

AI TOOLS REQUIRED:

1. ChatGPT
2. Python IDLE / Text Editor (Optional)

EXPLANATION:

A prompt-based application uses carefully designed natural-language prompts to communicate with a Large Language Model (LLM). In this experiment, ChatGPT is used as a Personal Productivity Assistant. The assistant accepts natural-language requests, organizes tasks according to priority and deadlines, suggests suitable reminders and wellness activities, and adapts its responses according to user preferences.

PROMPT:

"Design a personal productivity assistant that can help manage daily tasks, schedule reminders, suggest wellness tips, and answer general queries. The assistant should interact using natural language and be adaptable to the user’s changing preferences over time."

PROCEDURE:

1. Define the core requirements of a personal productivity assistant.
2. Identify and construct appropriate prompts for each task using ChatGPT.
3. Simulate natural user interaction through a simple interface or command-line system.
4. Collect feedback or inputs from users and adapt the responses accordingly.
5. Use basic memory to simulate preference adaptation.
6. Compare the outputs generated using simple and advanced prompts.

PROGRESSIVE PROMPT DESIGN:

LEVEL 1 – SIMPLE PROMPT:

"Help me organize my daily tasks."

OUTPUT:

The assistant provides a basic list of tasks and suggests an order for completing them.

LEVEL 2 – SPECIFIC PROMPT:

"Organize my tasks into high, medium and low priority based on urgency and deadlines."

OUTPUT:

The assistant categorizes tasks according to their priority and deadline.

LEVEL 3 – ADVANCED PROMPT:

"Act as my personal productivity assistant. Organize my tasks based on priority, deadline and estimated time. Suggest a practical schedule, identify possible time conflicts, include short breaks, and provide a brief wellness tip. Adapt the schedule whenever I provide new tasks or preferences."

OUTPUT:

The assistant creates a structured schedule, prioritizes tasks, identifies conflicts, recommends breaks, and provides personalized wellness suggestions.

EXPECTED OUTPUT:

PERSONAL PRODUCTIVITY ASSISTANT FEATURES:

1. Daily Task Manager:

   * Accepts tasks using natural language.
   * Organizes tasks based on priority and deadlines.
   * Displays pending and completed tasks.
   * Provides a daily task summary.

2. Smart Scheduler:

   * Understands natural-language scheduling requests.
   * Suggests suitable time slots.
   * Identifies overlapping tasks or appointments.
   * Helps manage available time efficiently.

3. Wellness Tips Generator:

   * Provides suggestions for hydration, exercise and breaks.
   * Recommends screen-time breaks during long study sessions.
   * Adapts suggestions according to user preferences.

4. General Query Assistant:

   * Answers general questions using natural language.
   * Provides explanations and suggestions when required.

5. Preference Adaptation:

   * Adjusts responses based on user feedback.
   * Can remember preferences such as preferred study time, task priority and break duration.

SAMPLE INTERACTION:

USER:

"I have an assignment due tomorrow, a class at 10 AM and I need to study for two hours."

ASSISTANT:

"Here is a suggested plan:

8:00–9:00 AM – Work on the assignment – High Priority

9:00–9:30 AM – Breakfast and preparation

10:00–11:00 AM – Class

11:30 AM–12:30 PM – Complete assignment

12:30–12:45 PM – Short break

2:00–4:00 PM – Study – High Priority

Wellness Tip: Take a 5–10 minute break after every 45–60 minutes of focused work."
